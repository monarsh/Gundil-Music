The first release of Gundil Music: a YouTube Music style player you host yourself, which can also play through Bluetooth speakers.

## Highlights

- **Laid out like YouTube Music** on desktop and phone:
  - Home: mood chips, Quick picks, Listen again.
  - Explore: new releases, charts by country, moods & genres.
  - Search: suggestions, a top result, and filters for songs, videos, albums, artists and playlists.
  - Album, artist and playlist pages.
- **Now playing**: Up next with autoplay radio, time-synced lyrics, Related, shuffle and repeat.
- **Your library on your server**: thumbs up/down, Liked Music, your own playlists, saved albums and playlists, subscribed artists, history, recent searches. No Google account needed.
- **Speakers & Bluetooth** (cast button): play on the device in your hand or on the server. On Linux the server can scan, pair and connect Bluetooth speakers itself, so a headless Raspberry Pi or Orange Pi becomes a music box you control from your phone. Speakers reconnect on their own after a reboot.
- **Lock-screen and headset controls** in the browser, and the app installs to the home screen.
- Optional login with `-auth user:password`.

## Downloads

| Platform | File | How to set it up |
|---|---|---|
| Headless Raspberry Pi 3 / 4 / 5 (64-bit OS) | `gundil-music-linux-arm64` | `bash install.sh` on the Pi |
| Headless Orange Pi PC (Armbian), or a Pi on a 32-bit OS | `gundil-music-linux-armv7` | `bash install.sh` on the board. The Orange Pi PC needs a USB Bluetooth dongle |
| Linux desktop | `gundil-music-linux-amd64` | See *Linux desktop and Windows* below |
| Windows 10/11 | `gundil-music-windows-amd64.exe` | See *Linux desktop and Windows* below |
| Android | `gundil-music-android-arm64` | See *Android* below |

`install.sh` installs everything else the board needs: mpv, BlueZ, PipeWire, Python with ytmusicapi and yt-dlp, and a JavaScript runtime for yt-dlp (Deno, or Node.js 22 on 32-bit boards). It also starts Gundil Music at boot and prints the address to open.

### Linux desktop and Windows

1. Install Python 3, then run `pip install -U ytmusicapi "yt-dlp[default]"` (on Windows: `py -m pip install ...`).
2. Install [Deno](https://deno.com) (Windows: `winget install DenoLand.Deno`) or Node.js 22+.
3. Optional: install [mpv](https://mpv.io) so the server can play through its own speakers.
4. Run the binary and open `http://localhost:8338`.

### Android

Most people should just open their Gundil Music server's address in Chrome and choose **Add to Home screen**.

To make the phone itself the server, install [Termux](https://f-droid.org/packages/com.termux/) and run `install-termux.sh` inside it.

## Known limitations

- Gundil Music uses YouTube Music's unofficial web API (via ytmusicapi) and yt-dlp. It isn't affiliated with YouTube or Google, and using YouTube this way may be against YouTube's Terms of Service. It's meant for personal use.
- YouTube changes often. If songs stop playing, update yt-dlp: `bash update-youtube.sh` on a Pi, or `pip install -U yt-dlp ytmusicapi`.
- Raspberry Pi 1 and Pi Zero (ARMv6) are not supported, because yt-dlp has no usable JavaScript runtime there.
- In-app Bluetooth pairing works on Linux only. On Windows and Android, pair in the system settings.
- There is no Google sign-in, so YouTube's own personalised recommendations and your YouTube library aren't available.
- Without `-auth`, anyone on your network can use the player. Don't expose it to the internet.

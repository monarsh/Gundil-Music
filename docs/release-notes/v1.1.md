Gundil Music 1.1 adds Android apps, a Linux AppImage and a Windows download that needs nothing else installed.

## New in 1.1

- **Android app (APK).** It connects to your Gundil Music server, finds servers on your Wi-Fi by itself, and keeps playing with the screen off. You get a media notification, lock-screen controls and Bluetooth headset buttons.
- **Windows: unzip and double-click.** The zip includes Python, ytmusicapi, yt-dlp and Deno. It opens Gundil Music in your browser.
- **Linux desktop AppImage.** One file with everything bundled. Make it executable and run it.
- The server finds `mpv` placed next to the program, for playing through the PC's own speakers.
- **Fixes.** The Android/Termux server now resolves domain names; Windows finds a real Python install rather than the Microsoft Store shortcut.

### How the pieces fit

Gundil Music is a server plus a player. The server streams from YouTube Music and keeps your likes, playlists and history. You open the player on any device:

- **Headless Pi or Orange Pi:** the board is the server. Phones use the Android app, and computers use a browser. Connect a Bluetooth speaker from the app's cast button and the board plays through it.
- **Windows or Linux desktop:** the PC is the server and opens the player in your browser. Phones on the same Wi-Fi can use it too.
- **Android app:** a player for a server elsewhere on your network. It plays on the phone (and its Bluetooth headphones) or remote-controls what the server is playing.

The three APKs contain the same app: it has no native code. The ARM64 one is right for nearly every current phone.

## Known limitations

- **APK updates.** This build is signed with a key made for this release, so installing a later APK may require uninstalling this one first.
- **Unofficial YouTube access.** Gundil Music uses YouTube Music's unofficial web API (ytmusicapi) and yt-dlp. It isn't affiliated with YouTube or Google, and using YouTube this way may be against YouTube's Terms of Service. It's meant for personal use.
- **YouTube changes often.** If songs stop playing, update yt-dlp: `bash update-youtube.sh` on a Pi, or see the README in the Windows zip.
- **Raspberry Pi 1 and Pi Zero** (ARMv6) aren't supported.
- **In-app Bluetooth pairing works on Linux servers.** On Windows and Android, pair in the system settings.
- **No Google sign-in.** YouTube's personalised recommendations and your YouTube library aren't available.
- **No login by default.** Without `-auth`, anyone on your network can use the player.
